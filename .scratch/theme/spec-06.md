## src/palette.ts — public interface (the seam under test)

```ts
export const ROLES = ["base","surface","overlay","border","muted","subtle","text","bright","accent","accent-quiet","on-accent","error","error-bright","warning","warning-bright","blue-tint","blue-tint-bright","magenta-tint","magenta-tint-bright","cyan-tint","cyan-tint-bright"] as const;
export type Role = (typeof ROLES)[number];
export type Oklch = readonly [l: number, c: number, h: number];

export function oklchToHex(l: number, c: number, h: number): string;   // lowercase "#rrggbb", sRGB, clipped
export function contrast(hexA: string, hexB: string): number;          // WCAG 2.x ratio, >= 1
export function mixOklab(fgHex: string, bgHex: string, amount: number): string; // amount of fg over bg, mixed in oklab, lowercase hex

export interface Lichen {
  name: "lichen";
  roles: Record<Role, { oklch: Oklch; hex: string; meaning: string }>;
  hex(role: Role): string;
  ansi: readonly string[];                       // 16 hex values in slot order
  syntax: Record<string, Role>;                  // straight from palette.json
  diff: { added: string; deleted: string; changed: string };   // background hexes: mixOklab(hex(role), hex("base"), mix)
}
export function loadPalette(json?: unknown): Lichen;   // default: the repo's palette.json
export const lichen: Lichen;                            // loadPalette()
```

oklch → hex algorithm (Björn Ottosson): oklch → oklab (a = c·cos h°, b = c·sin h°) → LMS' via `l_ = L + 0.3963377774a + 0.2158037573b; m_ = L − 0.1055613458a − 0.0638541728b; s_ = L − 0.0894841775a − 1.2914855480b` → cube → linear sRGB via `r = 4.0767416621l − 3.3077115913m + 0.2309699292s; g = −1.2684380046l + 2.6097574011m − 0.3413193965s; b = −0.0041960863l − 0.7034186147m + 1.7076147010s` → clip each to [0,1] → sRGB gamma (`x ≤ 0.0031308 ? 12.92x : 1.055x^(1/2.4) − 0.055`) → `Math.round(x·255)`. `mixOklab` goes hex → linear sRGB → oklab, lerps, and back.

## Tests (bun test) — work test-first, one vertical slice at a time

1. `src/palette.test.ts`: `oklchToHex` against ≥ 4 of the literals above (base, accent, error, blue-tint); `ROLES` equals `Object.keys(palette.json.roles)` in order; every role's `hex` matches the literal table; `ansi` is 16 entries and `ansi[10] === "#d4fd80"`, `ansi[0] === "#0f0f0f"`, `ansi[15] === "#f5f5f5"`; the contrast gates; `diff.added/deleted/changed` are lowercase hex that differ from base and from each other; `loadPalette` throws a readable error when a role in `ansi`/`syntax`/`diff` isn't in `roles`.
2. `src/emit/ghostty.test.ts`: `ghostty.render(lichen)` equals the exact string; `ghostty.path === "ports/ghostty/lichen"`.
3. `src/build.test.ts`: in a temp dir, `build(tmp, {check:true})` reports the ghostty path stale; after `build(tmp, {check:false})` the file exists with the exact content and a second check reports nothing stale; corrupting the file makes check report it stale again.
